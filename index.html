C++ Console Horror Game

Camp Woodwreath

Camp Woodwreath is an interactive supernatural horror game developed in C++20. Players take the role of a young hunter investigating mysterious disappearances near Grand Portage, Minnesota. Their decisions influence the investigation, relationships, and ending.

Key Features

  • Branching Storyline with Three Endings (For Now)
  • Collectible Lore that Unlocks Hidden Paths.
  • Player Status Screen and Input Validation.

What I Learned

Developing Camp Woodwreath helped me strengthen my understanding of C++ programming, branching logic, debugging, and organizing a larger project. One challenge I encountered involved conditional dialogue choices not appearing correctly because of an early return statement. By debugging the affected code and testing different story paths, I was able to identify and resolve the issue. This experience taught me the importance of carefully managing program flow, testing multiple outcomes, and maintaining organized code.
